## 作品について

昭和 9 年（1934 年）に聖公会出版社から出た、旧約聖書の続篇（アポクリファ）の文語訳。エズラ第一書・第二書、トビト書、ユデト書、ソロモンの智慧、ベン・シラの智慧、バルク書、マカビー第一書・第二書など 15 書を収める。旧約聖書続篇翻訳委員の訳。国立国会図書館の目次の字のままの見出しが付く。巻頭の言・序・解題も底本のとおりに収める。

## 底本

- [旧約聖書続篇 : アポクリフア](https://dl.ndl.go.jp/pid/1209337)（旧約聖書続篇翻訳委員 訳・聖公会出版社・1934年）。国立国会図書館の全文テキスト（OCR）のまま

国立国会図書館デジタルコレクションの「インターネット公開（保護期間満了）」の資料です。

## 本文の作り方

国立国会図書館デジタルコレクション（インターネット公開）の全文テキスト（OCR）をそのまま収めた。1 段落が底本の 1 コマ（見開き）。校正はしていないので、振り仮名や柱の混じり、読み違いが残る。
